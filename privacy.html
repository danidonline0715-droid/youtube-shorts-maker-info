개인정보처리방침

YouTube Shorts Maker · 작성일: 2026년 9월 30일

1. 적용 범위와 운영자

이 방침은 수달도 출근해 채널 운영자가 개인 PC에서 사용하는 YouTube Shorts Maker와 이 안내 사이트에 적용됩니다. 일반 방문자에게 계정 가입이나 Google 계정 연결을 제공하는 서비스가 아닙니다. 앱은 YouTube API Services를 사용합니다.

2. 접근하거나 보관하는 정보

  • Google OAuth 액세스 토큰, 갱신 토큰, 만료 시각, 승인 범위
  • 연결된 YouTube 채널의 ID와 이름
  • 업로드 영상 ID·주소, 처리 상태, 게시 이력 및 관련 오류 기록
  • 운영자가 준비한 대본, 이미지, 음성, 자막, 영상, 제목·설명 등 로컬 제작 자료

앱은 Google 계정 비밀번호를 수집하거나 저장하지 않습니다. youtube.upload 권한은 영상 업로드에, youtube.readonly 권한은 채널 식별 및 영상 처리 상태 조회에 사용합니다.

3. 이용 목적과 외부 전송

Google 계정 연결 유지, 업로드 대상 채널 확인, 운영자가 지정한 영상 전송, 처리 결과 확인과 오류 진단을 위해 정보를 사용합니다. 토큰 교환·갱신 시 인증 정보가 Google로 전송되고, 업로드 시 영상 파일과 제목·설명·태그·공개 범위가 YouTube로 전송됩니다.

Google·YouTube에서 받은 인증 토큰과 채널 데이터는 광고, 판매 또는 AI 모델 학습을 위해 사용하지 않습니다. 현재 Codex·로컬 도구 제작 경로는 대본과 이미지 생성에 OpenAI의 Codex 및 내장 이미지 생성 기능을 사용하고, 더빙·자막 타이밍·영상 합성은 PC에서 처리합니다. 제작 지시나 생성용 자료가 OpenAI에서 처리될 수 있으나 Google 인증 토큰을 생성 프롬프트에 포함하지 않습니다. OpenAI의 데이터 처리에는 OpenAI 개인정보처리방침과 이용 계정에 적용되는 약정이 적용됩니다.

Google 및 YouTube의 데이터 처리에는 Google 개인정보처리방침이 적용됩니다.

4. 보관과 보호

OAuth 토큰과 연결 채널 정보는 운영자 PC에 AES-256-GCM으로 암호화하여 저장합니다. 암호화 키와 클라이언트 보안 비밀은 같은 PC의 로컬 설정에 있으므로 PC 및 파일 접근 권한 관리가 필요합니다. 제작 자료와 게시 이력은 로컬 프로젝트 파일로 보관하며, 이들 파일 전체가 암호화되는 것은 아닙니다.

현재 구현은 전체 제작 자료와 게시 이력을 정해진 기간 후 자동 삭제하지 않습니다. 운영자가 필요한 기간을 판단해 로컬 파일과 백업을 관리합니다. 연결 해제 기능은 저장된 토큰과 그 안의 채널 정보를 삭제하지만 별도 프로젝트 파일이나 게시 이력까지 자동 삭제하지는 않습니다.

5. 연결 해제, 권한 철회 및 삭제

  1. 자동화를 중지하고 로컬 앱의 YouTube 연결 해제를 실행하면 암호화된 인증 파일이 삭제됩니다.
  2. Google 계정의 연결된 앱 관리에서도 이 앱의 접근 권한을 철회할 수 있습니다. 로컬 연결 해제만으로 Google 측 권한이 철회되지는 않습니다.
  3. 나머지 로컬 채널·업로드 관련 데이터, 프로젝트 자료, 로그 및 백업 삭제가 필요하면 운영자에게 요청하거나, 개인용 앱 운영자가 직접 해당 파일을 삭제합니다. Google에서 권한을 철회했다고 기존 로컬 파일이 모두 자동 삭제되지는 않습니다.

이미 YouTube에 업로드된 영상은 로컬 파일 삭제나 연결 해제로 삭제되지 않습니다. 해당 영상은 YouTube Studio에서 직접 관리할 수 있습니다.

6. 안내 사이트와 호스팅

이 안내 사이트에는 자체 방문자 분석, 광고, 입력 폼, 추적 스크립트 또는 쿠키 설정 코드를 넣지 않습니다. GitHub Pages에 게시되는 경우 호스팅 제공자가 요청 IP 주소 등 접속 정보를 처리할 수 있습니다. 자세한 내용은 GitHub 개인정보처리방침을 참고해주세요.
